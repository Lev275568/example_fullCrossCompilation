В папку tools скачать официальные сборки:
- cmake 4.5.0-rc1: https://cmake.org/download/ 
- LLVM 23.1.4: https://github.com/llvm/llvm-project/releases/
- ninja-build 1.13.2: https://github.com/ninja-build/ninja/releases/
куда конкретно подкладывать смотреть в run.sh.

Внутри файла run.sh, между BEGIN CONFIG/END CONFIG подправить пути. (по умолчанию настроены на Debian 13)
